# Contributing to FraudShield AI

Thank you for your interest in improving FraudShield AI.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make a focused improvement.
4. Test the application locally.
5. Open a pull request describing what changed and how you tested it.

## Contribution guidelines

- Keep changes clear and easy to review.
- Do not commit API keys, `.env` files, credentials, or personal financial information.
- Use synthetic sample messages for testing.
- Do not claim that the prototype can guarantee fraud detection.
- Include relevant test steps when changing detection behavior.

## Reporting an issue

When reporting a bug, include:
- A short description of the issue.
- Steps to reproduce it.
- Expected behavior.
- Actual behavior.
- Relevant error messages with secrets and personal information removed.
